# Orders Cleaner

Небольшой Go API для получения, очистки и дедупликации заявок.

## Endpoints

- `GET /api/clients` — текущий результат в формате `clients` + `stats`.
- `POST /api/sync` — заново загрузить исходные заявки и атомарно заменить результат.
- `GET /health` — health check.

По умолчанию источник: `https://test.ooobs.ru/api/orders`. Его можно переопределить переменной окружения `SOURCE_URL`. Порт задаётся через `PORT` (по умолчанию 8080).

## Локальный запуск

Требуется Go 1.22+.

```sh
go test ./...
go run .
```

Затем откройте `http://localhost:8080/api/clients`.

## Деплой на Render

1. Загрузите файлы проекта в GitHub-репозиторий.
2. В Render выберите **New + → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml`, соберёт Dockerfile и выдаст публичный URL.
4. Откройте `https://<имя-сервиса>.onrender.com/api/clients`.

Если источник временно недоступен при старте, сервер всё равно запускается; повторите синхронизацию запросом `POST /api/sync`.

## Правила обработки

- Принимаются номера из 10 цифр (добавляется `+7`), 11 цифр с начальной `8` (заменяется на `+7`) или с начальной `7` (добавляется `+`).
- Невалидные номера отбрасываются.
- Для каждого нормализованного номера выбирается запись с максимальным `amount`; при равенстве — с более поздним `created_at`.
- `duplicates_merged` = количество валидных заявок сверх одной на каждого уникального клиента.
- Синхронизация заменяет целиком текущий снимок, а не добавляет строки, поэтому повторный запуск не накапливает дубли.
